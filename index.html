MODEL ARCHITECTURE

How the Prediction Engine Works

The predictor is trained on historical cruise voyage manifest data. When you submit a passenger profile, the application performs:

01

Feature Extraction

Parses courtesy titles, calculates total party size (SibSp + Parch + 1), and flags solo traveler status.

02

Vector Encoding

Maps gender, embarkation ports, and titles into deterministic one-hot encoded vectors calibrated with dataset medians.

03

Ensemble Prediction

Executes Logistic Regression and Random Forest models, generating an ensemble consensus survival percentage.

04

Diagnostic Audit

Assesses each feature to produce human-readable positive and negative safety factor explanations.
